# NBACollectEval
   - **Discord bot** for a peer-to-peer trading server.
   - Helps users query pricing, record transactions, and get notifications for favorite players being sold.
   - Uses Google Sheets as the source of truth for pricing and transaction history.

## Project structure
- `bot/` — Discord bot implementation and Google Sheets integration.
- `config.example.json` — Example configuration for bot.
